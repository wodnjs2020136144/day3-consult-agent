# 반품·환불 규정

## 단순 변심 반품
- 상품 수령일로부터 **7일 이내**에만 단순 변심 반품이 가능합니다.
- 반품 배송비는 고객 부담이며, 최초 배송비가 무료였던 주문은 반품 시 배송비가 차감됩니다.
- 포장을 개봉했거나 사용 흔적이 있는 상품은 단순 변심 반품이 불가합니다.

## 상품 하자·오배송 반품
- 상품 하자 또는 오배송의 경우 **수령일로부터 30일 이내** 반품이 가능하며, 배송비는 전액 판매자 부담입니다.
- 하자 사진 또는 영상 첨부 시 처리 속도가 빨라집니다.

## 환불 절차
1. 상담 채널에서 환불을 접수합니다(즉시 처리되지 않습니다).
2. 담당자 승인 후 결제 수단으로 환불이 진행됩니다.
3. 환불은 승인일로부터 영업일 기준 3~5일 소요됩니다.
