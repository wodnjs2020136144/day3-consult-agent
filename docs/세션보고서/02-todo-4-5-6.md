## 트러블슈팅 — RAG 검색 결과가 항상 빈 배열

**증상**: `QuestionAnswerAdvisor`를 통한 규정 질문에 "정보를 제공할 수 없습니다" 식 거절 답변이
나오고, `RETRIEVED_DOCUMENTS` 컨텍스트가 항상 빈 리스트.

**원인 조사**: `VectorStore.similaritySearch()`를 `similarityThreshold(0.0)`으로 직접 호출해
실제 코사인 유사도 점수를 확인한 결과, 정답 청크(반품 규정)의 점수가 **0.487**로,
`application.yml`의 `day3.rag.threshold: 0.5`보다 낮아 전량 필터링되고 있었다.
`text-embedding-3-small` 임베딩의 한국어 짧은 질의-문서 쌍에서는 코사인 유사도가 0.5를
잘 넘지 못하는 경우가 흔하다.

**해결**: `Day3Properties` Javadoc이 "실습에서 조정할 값을 코드가 아니라 설정으로 뺀다"고 명시한
그대로, `application.yml`의 `day3.rag.threshold`를 **0.5 → 0.35**로 낮췄다(코드가 아닌 설정
튜닝이라 "손대지 않는" 완성 소스 코드 범위 밖). 재검증 결과 정답 청크(score 0.484)가 정상 통과해
출처 있는 답변이 나왔다.

**교훈**: 실제 임베딩 모델의 유사도 점수는 직관보다 낮게 나올 수 있다 — RAG가 "검색 결과 없음"으로
보일 때는 프롬프트·Advisor 순서보다 **threshold부터 실측**해 볼 것.
